
# 2026-11-21 · CIELO 天空鲸城：从参考图到可游览的幻想都市

> 新项目，与「天空之城 · 灯祭」（CELESTIA）共用同一套自研单文件 WebGL2 引擎思路，
> 但美术、世界、模块全部重写。参考图：F:/AI/dsh/素材/图片/幻想城市/整体原图.png
> （另有 建筑/、空中巨大鲸鱼/、高架铁轨火车/ 三组子参考图）。

## 目标
用户要一个「**可以游览的幻想城市**」，精准还原参考图的日系动画风白金石造欧陆都市：
巨鲸背城堡、白色钢架玻璃穹顶宫、哥特金钟楼、钢桁架高架蒸汽列车、大理石露台、锦鲤与白鸽。

## 做了什么

### 00:15–00:40　立项 + 骨架
- 新建 01-source/cielo/，从 skycity 复用 gl/math/geo/fx/audio 与 tools（serve/shot/sheet），
  重写 palette / shaders / main / camera / world / template。
- 关键改造：GLSL 拆成 src/glsl/*.glsl（esbuild text loader 内联），shader 报错能看真实行号；
  新增 lib3d.js（通用几何件 + MT 材质预设）、actor.js（实例化 actor + TRS）、layout.js（唯一锚点表）。
- 渲染管线确定为：太阳阴影 → 天空 → 合并静态 mesh（单 draw call）→ 动态 actor →
  billboard → 加法 → bloom → FXAA/调色合成；自适应分辨率。

### 00:40–01:00　三次真 bug
1. b.push() 矩阵只写 15 个数（漏末位 1）→ 整个变换栈变 NaN、之后所有几何消失。
   在 geo.js 加了修复 + 警告，并扫掉 lib3d/world 里的四处方括号。
2. 天空 basis 的 up 向量写成了 forward × right（正好反了）→ 整片天空上下颠倒。
3. bill pass 忘了传 uProj/uView → 所有 billboard（云海/气球/蒸汽/光尘）塌到原点不可见。
   这条是 life 子代理发现的，很关键。

### 01:00–01:35　并行内容（5 个子代理，各自一个文件域）
- **architect**：arch.js Beaux-Arts 生成器（檐口/巨柱/拱窗/栏杆/山花/孟莎顶/穹顶/尖塔/雕像）
  + city.js（大道/街区/广场喷泉/运河/远景天际线）→ 全场景 91.5 万 tris（构建 1.06 s）。
- **landmark**：landmark.js 哥特双塔 120 m（4 面金钟）+ 白钢玻璃穹顶 125 m + 摩天轮 + 车站。
- **whale**：whale.js 260 m 巨鲸 + 背上小城 + 光尘；rail.js 钢桁架高架 4.7 万 tris + 蒸汽机车。
- **stage**：terrace.js 弧形雕花露台/拱廊/台阶/花盆藤蔓 + hero.js 金发少女（白裙/蓝缎带/花束）+ 黑猫。
- **life**：life.js 锦鲤 4 群 / 白鸽 3 群 / 长颈鹿 2 只 / 气球簇 / 彩纸 / 热气球 / 双翼机 / 藤蔓。
- 主树同时接：阴影贴图（2048² PCF）、FXAA、程序化环境音（风/和声垫/钟声/鲸歌/汽笛/鸽子）、
  电影巡游样条（24 个控制点，108 s 一圈）、8 个观景点、开场推镜。

### 01:35–　收尾
- 光照方向是这轮最关键的调参：主光必须在相机侧（sunDir.z > 0），否则城市立面全是蓝灰阴面；
  代价是露台上的少女背对相机（正好），栏杆朝相机一侧受光。
- 反照率从近白降到 0.45–0.85，雾密度 0.0008，饱和度 1.26，才得到参考图那种「米白石材 + 深蓝天空」。
- 最后一个视觉 bug：贯穿全屏的橄榄绿亮带 —— 每栋楼孟莎顶金脊线 + 檐口金线同高成排，
  过曝连成跨屏亮带；改成哑光石材 + 四角金饰后消失。
- 已知遗留：少女模型仍偏简（4.5k tris、背对相机受光，正面脸部可读性有限）；运河是贴地浅水渠。

# 2026-11-21 · 第二轮（下午）：巨鲸重做「整头鲸鱼 + 鲸背城市」

## 目标
用户传了两张图（当前效果 + 参考图）并提了 4 条：
1. 城堡太靠后了；2. 城堡下面不需要有大圆盘的土地，城堡应该长在鲸鱼背上；
3. 鲸鱼还要放大好几倍（参考图 2：鲸鱼后背上是另一个城市；角色所在城市只是众多鲸鱼城市之一）；
4. 鲸鱼的样子做得再像一些、做精细。

## 做了什么（13:00–14:30）

### 1) 鲸鱼整体重写（`src/whale.js`）
- 尺寸：局部 260 m 不变，渲染 **×3 → 世界 780 m 长**；巡游高度 158→420 m、半径 240→340 m。
- 剖面表重做（20 个 KEYS）：钝头大嘴 / 深喉 / 收细尾柄；顶面平坦指数在城市段 4.4~4.8，
  压出给城市站的宽阔平背。
- 真几何喉褶、双喷气孔、眼、藤壶、旧疤、白腹分色（带 noise 扰动的边界）、脊背亮带。
- 鳍重做：自写 `airfoilFin()` 翼型发生器 → 长胸鳍 / 带缺口的宽尾鳍 / 钩状背鳍。
- 新着色器 `glsl/whale.fs.glsl`（wrap 主光 + 云层反弹 + 取消自阴影），`main.js` 加 `whale` 程序。

### 2) 鲸背城市（新文件 `src/whale-city.js`，子代理 citysmith）
- 真实米制、y=0 平地、+Z 朝鲸头；哥特大教堂（73 m 双塔 + 玫瑰窗 + 飞扶壁）+ 25 栋街区 +
  八边形城墙城门 + 喷泉广场 + 花园；3.9 万面，自检 `tools/backcity-check.mjs`。
- 主代理用 `1.12×` 真实米制缩进鲸鱼局部空间并挪到鲸背前段（z=43 中心）。
- 删掉旧「大圆盘」：`backShelf()` 用岩台 + 挡土墙 + 岩石 + 藤蔓 + 鲸皮起隆，把城市「种」进鲸背。

### 3) 众多鲸鱼城市
- `POD`：4 头远空鲸（低模 + 塔楼剪影），不同轨道/高度/大小；观景点 2/7 能看到。

### 4) 相机 / 观景
- 相机飞行上限 y≤1150；巡游样条加高；观景点 2「鲸临城上」= 阳光侧鲸城全貌；
  观景点 7「云上鲸背」= 鲸背城市 + 远处鲸群。

### 5) 修 bug
- `arch.js mansard()` 山花 `b.quad` → `b.tri`（`MT.stone` 当颜色的 NaN 源，第一轮荧光条的根因）。
- `city.js:923` `mulc(C.lawn, C.leafLight, 0.2)` → `mixc`。
- `geo.js B.vert()` 加坏颜色兜底 + 调用栈警告。
- `shot.mjs` 视角切换：`__cielo.setView(i)` 要传 `cam.setView(i, true)` 才是瞬切（FREEZE 下过渡不动）。

## 坑与发现
- 巨鲸太大（780 m）后：相机在它附近很容易进入体内（看到蓝色内壁）；调机位要先按「离轴 ≥200 m」
  算，别凭感觉。
- 巨鲸的 shadow map 自遮蔽会在腹面留一道硬边 → whale 着色器直接跳过阴影。
- 视角切换用 `setView(i,true)`，否则 FREEZE 下停在过渡起点（这一轮因此白截了好几张图）。
- 鲸背城市的「城市感」靠屋顶颜色和教堂尖塔；从正上方看板岩顶偏暗，后续可考虑给鲸城单独一套夜灯。
