# 每日记录 · 工作日志

这里按日期记录每天做了什么，**给未来的自己（或新会话）看**。

## 约定

- 一个工作日一个文件：`YYYY-MM-DD.md`，用中文写，不求文采，求「三天后还能看懂」。
- 每条记录固定五段：**目标 / 做了什么 / 动了哪些文件 / 产物 / 坑与发现 / 下次接着做**。
- 重要的决策与参数写进文件，别只留结论（例：为什么鳍改用预乘 alpha）。
- 当天的成品图片、视频、单文件 HTML 都放 `04-output/`，这里只写路径。
- 收尾时顺手更新根目录 `HANDOFF.md`（如果项目归属有变）。
- 新建条目：复制 `_template.md`，改名字。
