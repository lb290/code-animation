# 每日记录 · 工作日志

按日期记录每天/每段会话做了什么，**给未来的自己（或新会话）看**。

## 约定（完整规范见 [../03-notes/worklog-format.md](../03-notes/worklog-format.md)）

- 一个工作日一个文件：`YYYY-MM-DD.md`，中文，不求文采，求「三天后还能看懂」。
- 固定六段：**目标 / 做了什么 / 动了哪些文件 / 产物 / 坑与发现 / 下次接着做**。
- 写**事实、数字、路径、命令**；不写「调了一下午」。
- 「坑与发现」必须写清**根因**；未完成写 🚧 / ⏸ 并说明等什么。
- 成品图片、视频、单文件 HTML 都放 `04-output/`，这里只写路径。
- 收尾时同步更新根目录 `STATUS.md`（现状）和 `HANDOFF.md`（本轮历史）。
- 新建条目：复制 [`_template.md`](_template.md)，改名字。
