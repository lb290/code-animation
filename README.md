# 代码动画（code-animation）

用纯代码生成动画视频的**研究 + 作品集**。没有素材、没有剪辑软件、没有 GPU 也能做：
画面来自 numpy 数组运算或手写 WebGL，音频来自加法合成或 WebAudio，帧直接经 stdin 灌进 ffmpeg。

两个方向的产出：
1. **线性影片**（AETHER，下方）——numpy 粒子 + HDR 光栅 + ffmpeg。
2. **可游览场景**（天空鲸城 · 天空之城）——手写 WebGL2 的实时 3D 世界，浏览器里自由飞行。

## 平板 / 手机怎么用（安卓）

CIELO 支持触屏：左半屏按住拖动 = 摇杆飞行，右半屏拖动 = 转视角（两只手可同时操作），右侧「升 / 降」，右下角 **☰** 展开动作条（巡游 / 观景 / 导览 / 昼夜 / 烟花 / 摄影 / 明信片 / 露台 / 帮助 / 全屏），默认收起、选完自动收回。抵达地标不再自动弹导览卡片，只在 ☰ 上挂「新」角标，点开才读。触屏默认走「流畅」画质档（关阴影、降渲染分辨率），桌面端行为不变。

> 版本自查：标题页/帮助面板底部有**构建戳**；在地址后加 `?diag` 可看构建、协议、静态三角数（当前完整构建 = 2,048,729 tri）、观景点与抄本页数。拷到平板的单文件如果三角数/构建戳不对，就是旧文件——重新拷最新的 `04-output/CIELO.html`，或直接用上面的 Pages 安装。

三种用法，任选：

| 用法 | 怎么做 | 适合 |
|---|---|---|
| **局域网（电脑当服务器）** | 电脑上 `cd 01-source/cielo` → `node tools/serve.mjs --host=0.0.0.0`，它会打印 `http://192.168.x.x:8099/CIELO.html`；平板连同一个 WiFi，用 Chrome 打开这个地址 | 真机联调、改完立刻看 |
| **装到平板主屏幕（推荐，可离线）** | 平板 Chrome 打开 <https://lb290.github.io/code-animation/04-output/CIELO.html> → 菜单「添加到主屏幕 / 安装应用」；装好后断网也能打开（service worker 缓存单文件） | 日常玩、出门看 |
| **单文件带走** | 把 `04-output/CIELO.html`（约 0.9 MB）拷到平板，用 Chrome 打开本地文件 | 完全没有网络时 |

画质档可以用 URL 参数强制：`?q=low|mid|high`（默认：触屏 low、桌面 high；开局 150 帧后还会按实测帧时间自动调一档）。`?touch=0` 可在平板上退回桌面式键盘操作。

> 平板建议横屏；竖屏（窄于 760 px）会显示「把平板横过来」的轻提示，可点掉。iOS Safari 未专门适配。

## 成片 AETHER

| 时间 | 镜头 | 实现 |
|---|---|---|
| 0–5s | 尘埃球收束成 Thomas 吸引子 | 13 万粒子 RK4 积分 + 透视投影 |
| 5–11s | 流场丝绸 | 10 个正弦波叠成的流函数解析旋度，3 万粒子 ×6 子帧（180° 快门） |
| 11–17s | 炸开再回聚的环面纽结 | 16.5 万粒子，(2,3) 纽结管状分布，末尾塌缩成星 |
| 17–23s | AETHER 标题 | 文字遮罩 + 三级高斯辉光 + 扫光 |
| 23–24s | 淡黑 | — |

后处理每帧：三倍频程 bloom → 阈值化变形宽银幕光带 → ACES 拟合曲线 →
青影暖高光分级 → 色差 → 暗角 + 时域颗粒 + 曝光闪烁 → raw RGB24 直灌 ffmpeg。

## 可游览场景 —— 天空之城 · 灯祭（CELESTIA）

**打开 `04-output/CELESTIA.html` 即可**（单文件 145.0 KB，无网络、无插件、双击运行）。

云海之上的浮空岛群，夜里点起灯：三层台地上的**仿古木构町屋小镇**（71 栋，环街两边夹出夜市）、
五重塔的金顶光柱与光环、钟楼、鸟居、成串的纸灯笼、七条巨型鱼灯（最长 30 单位）领着 20 条小鱼灯绕着城游、
瀑布从岛缘泻入虚空、96 盏天灯与烟花升起。

**建筑与街市（第二轮精细化）**：参考图里的多层木构町屋 → 程序化生成器 `buildings.js`：
半木构（暖白灰泥 + 深色柱梁）、深檐 + 椽头阵列、二层挑台 + 朱漆栏杆、格子窗 / 虫笼窗（暖纸自发光）、
腰檐、暖帘、横竖招牌、幡旗、山墙博风板与悬鱼、曲面瓦顶；三档建模 LOD（3.7k / 1.1k / 250 面，按街段分配）。
`street.js` 再铺 12 个屋台（条纹雨棚 + 食盒 + 摊灯）、9 道跨街灯串、7 杆幡、4 块竖招牌、5 处布雨棚；
`town.js` 把 71 栋按「内排朝外 + 外排朝内」沿环街排布，加石板街面，并提供稀疏远景排补齐天际线。
规格见 [03-notes/building-spec.md](03-notes/building-spec.md)。

鱼灯是两轮重做的部分：参考金鱼提灯的照片，把原来的低模「贴片鱼」换成
**纸灯本体 + 手撕拼贴纸面 + 六片半透明丝绸鳍**——身体里点着一盏灯（宽而弱的纸面发光 +
小而亮的灯芯），纸面用**量化噪声切成一片片手撕纸**（朱红/金/米白，偶尔一块青瓷玻璃纸，
片与片之间是撕缝和金箔碎），外加两道旧金漆箍、竹骨环、鳃盖折痕与金瞳；
六片鳍用预乘 alpha 的独立 pass：根朱红→中珊瑚→梢玫瑰白的**三段色带**、鳍根金绑带、
27 条放射鳍脉、丝褶明暗、灯透过膜的逆光与视角相关虹彩；胸鳍是**水袖飘带**而不是叶片。
几何一次构建（高模 1.71 万面 / 低模 4.8 千 / tiny 3 千），27 条鱼只差矩阵与纸色种子。

| 键 | 作用 |
|---|---|
| W A S D | 飞行（相机朝向） |
| 鼠标 | 环视（点击画面锁定指针） |
| Q / E | 下降 / 上升 |
| Shift | 加速 |
| 空格 | 自动巡游开/关（Catmull-Rom 穿过全城） |
| 1 – 8 | 跳转观景点：云上之城 / 灯市 / 俯瞰 / 灯桥 / 鲤群 / 岛底 / 云海 / 高塔 |
| T | 时刻：灯祭夜 ↔ 薄暮蓝调 |
| P / H / M | 摄影模式 / 帮助 / 静音 |

技术要点：手写 WebGL2（无 three.js）、HDR 前向渲染 + 3 级 bloom + ACES、
8 盏点光（5 盏跟随最近的鱼灯、3 盏取最近灯笼）、顶点色烘焙 AO + 边缘光、
鱼灯双 pass（不透明纸身 + 预乘 alpha 丝绸鳍）+ 三档 LOD/视锥剔除、程序化 WebAudio 灯祭环境音。
全部几何、颜色、声音都是代码生成，仓库里没有任何图片/模型/音频文件。

性能（GTX 1070 Ti，实测整帧 GPU）：1280×720 约 0.5–0.7 ms（世界静态 mesh 17.7 万三角形）、
绘制 74 calls / 每帧 30–39 万三角形；headed 浏览器里的 56 fps 是 60Hz 垂直同步封顶。
场景内按 `?perf=1` 可看到 GPU 型号、渲染倍率、实测 ms 与「受垂直同步/串流限制」判定。

## 方法论（来自 03-notes/techniques.md）

1. **shots as data**：一个时间轴统治画面/配乐/字幕，改一处时间全片跟着走
2. **stills-first**：1/4 尺寸静帧 → critic → 全尺寸 → contact sheet → 才最终渲染
3. **峰值压强拍**：冲击核心 0.10–0.25s，硬切藏在画面覆盖最大处
4. **阈值化 bloom + 33³ LUT 调色**：泛光只从高光取，暗部不糊
5. **画面 = 时间的纯函数 + 固定种子**：可断点续渲、可逐帧比对
