# 天空之城 · 灯祭（CELESTIA）制作笔记

> 一个可以在浏览器里自由游览的「天空之城」夜景：浮空岛群、灯祭小镇、巨型鱼灯、
> 云海与月光、瀑布泻入虚空。**纯手写 WebGL2，零素材、零第三方库、单文件 102 KB。**

成品：`04-output/CELESTIA.html`（双击即可打开，离线可用）
静帧：`04-output/skycity/01…08.png` + 鱼灯特写 `09-fish-hero.png` / `10-fish-detail.png`

## 2. 场景里有什么

- **8 座浮空岛**：主岛（半径 62，倒锥形岩底深 120）+ 花园岛、神社岛、灯塔岛、远景巨岩等；
  岛底是分面噪声岩锥 + 悬垂钟乳 + 发光晶体 + 垂下的藤蔓。
- **灯祭小镇**（主岛三层台地）：**71 栋仿古木构町屋**（11-20 第二轮精细化：深檐 + 椽头、二层挑台 + 朱栏、
  格子窗 / 虫笼窗、暖帘、招牌、幡旗、腰檐，三档 LOD）、**12 个屋台摊位 + 9 道跨街灯笼串 + 7 杆幡旗 + 4 块竖招牌**、
  石板环街、五重塔（金顶 + 3 道光环 + 光柱）、钟楼（四面钟面）、鸟居、石灯笼。
- **7 条巨型鱼灯 + 20 条小鱼灯**：最大的一条 30 单位（约半个街区的长度），沿不同半径/高度的
  圆轨缓慢游动，纸灯身体内点着一盏灯，六片半透明鳍；最近 5 条各自携带一盏暖光点光，
  把光洒到下面的屋瓦上。小鱼灯穿插在塔与塔之间补足灯祭的密度。
  （11-20 从 26 减到 20：小鱼改 tiny LOD + 视锥剔除，密度靠种子重排保持。）
- **灯串与天灯**：岛与岛之间的悬链线灯串 5 条 + 环城 12 段；**96 盏天灯**自城中升起（11-20 从 240 减到 96）。
- **5 道瀑布**从岛缘泻下 150–220 单位，末段化为水雾（着色器内溶解）。
- **云海**：2600×2600 位移网格 + 3 次 fbm 的密度场伪法线光照；近岛处有积云团（实例化公告板）。
- **夜空**：双层星点 + 银河带 + 大月亮（暖白光晕）+ 高空薄云。
- **动态**：620 颗上升火星、96 盏天灯、每 5.5 s 一轮远处烟花（70–120 粒）。

## 3. 技术实现（`01-source/skycity/src/`）

### 3.1 渲染管线（`main.js` + `gl.js` + `shaders.js`）

```
sceneRT (RGBA16F + depth24, 0.75 分辨率)
  ├─ sky（全屏三角形 + 摄像机基向量求方向，星/月/薄云全部在片元里算）
  ├─ cloud sea（2600² 位移网格，fbm 密度场伪法线）
  ├─ 不透明静态网格（整座世界合并成 1 个 mesh：51.8 万顶点 / 17.7 万三角形）
  ├─ 鱼灯 ×33（body 不透明 pass + fins 预乘 alpha pass，顶点着色器摆尾/抖鳍）
  ├─ 瀑布（alpha 混合，UV 存在顶点色里）
  ├─ 积云公告板（实例化，预乘 alpha）
  ├─ 加性光效（光环 torus、光柱锥、火焰）
  └─ 公告板粒子（纸灯笼/火星/烟花，实例化，每帧 bufferSubData）
      ↓
bright pass (1/2) → 3 级 blur 金字塔 (1/2, 1/4, 1/8) → composite
      ACES 色调映射 + 提亮/染色 + 暗角 + 色差 + 胶片颗粒 + S 曲线
```

- **draw call 74**（视锥剔除后 44–74），每帧实际绘制三角形 30–39 万（鱼灯 17.1k 高模 / 4.8k 低模 / 3.0k tiny），
  单文件 145.0 KB（minify 后），无任何外部请求；真显卡整帧 GPU 仅 0.5–0.7 ms（720p–900p），
  headed 浏览器 56 fps 是 60Hz 垂直同步封顶。旧版写的「1280×720 17.6ms/帧」是 rAF 间隔被 vsync 卡住，不是渲染耗时。
- 顶点格式统一：`pos(3) normal(3) color(3) mat(2)`，`mat.x = 自发光`、`mat.y = 光泽`；
  同一套 lit shader 既能画石头木头，也能画发光的窗纸和金饰。
- 光照：月光方向光（wrap 漫反射）+ 半球环境（天光冷/地面暖）+ 城市面光源（按距离衰减的暖光）
  + **8 盏点光**（5 盏跟随最近的鱼灯、3 盏取最近的灯笼位）+ 边缘光（乘 albedo，避免整片泛蓝）。
- 雾：距离 × 高度衰减；云海单独用天空地平线色做空气透视，让海天无缝。
- 自适应分辨率：**按 gl.finish 实测整帧耗时**驱动（不是 rAF 间隔），>24ms 降档 / <11.5ms 升档，
  迟滞 2–3 次采样 + 45 帧冷却，倍率范围 0.55–1.0。旧版用 rAF 间隔 >27ms 就降档，
  在 30Hz 垂直同步/远程串流的机器上会被误判成「渲染慢」而白白降分辨率（已修）。
- 性能诊断：`?perf=1` 左下角覆盖层显示 GPU 型号、渲染倍率、实测 ms、显示 Hz、
  软/硬件渲染与「受垂直同步/串流限制」判定；同一份数据在 `__sky.perf.snapshot`。

### 3.2 程序化几何（`geo.js` + `world.js`）

自写一个 `B` 构建器（变换栈 + 顶点/索引累加）和一批原语：
`box / cylinder / lathe / roof（和风曲面屋顶，逐行色带当瓦）/ archWall / torus / ribbon / rockBlob / sphere / grid`；
第二轮为町屋追加了 `bar3 / fretGrid / railing / dougong / eaveRoof / roofGable`（见 §3.7）。
**B 的 push/pop 必须严格配对**：未配对的 push 会让之后所有几何静默位移（第二轮踩过，工具 `tools/stack-check.mjs`）。
屋顶、鸟居、五重塔、町屋、灯柱、石灯笼、桥、阶梯、瀑布面都是这些原语的组合。
岛是「环带网格顶面 + 悬崖带 + 噪声倒锥 + 尖刺 + 晶体」的四层结构。

### 3.3 鱼灯（`fish.js` + `FISH_VS/FISH_FS/FISH_FIN_FS`）

鱼灯是这次的主角。参考图里的金鱼提灯有三个特征：**纸里透出的灯心**、**拼贴的半透明纸面**、
**大水袖般透明的鳍**。实现上把它们拆成「几何 / 纸面 / 鳍」三层。

**几何（`buildFish(seed, lod)`，一次构建、全场景复用）**
- 鱼身：16 个关键剖面（宽、高、中心偏移）插值成 60 环 × 48 段的自定义「超椭圆」截面，
  背略扁、腹更鼓；首尾各补一个扇形封口，避免正面看穿管子。
- 六片鳍：尾鳍（上下两大叶 + 分叉 + 侧向折叠 + 皱边）、背鳍（长拖尾）、臀鳍、
  一对胸鳍、一对腹鳍，全部是参数曲面（根系曲线 + 展开方向 + 波浪扰动），
  鳍根埋进鱼身里，所以看不到接缝。
- 眼（黑漆珠）、唇环、口腔。顶点格式改成 12 float：
  `pos(3) normal(3) part/u/v(3) finId/tint/seed(3)` —— 片元着色器靠 (part,u,v) 直接
  算面板、鳞片、竹骨、鳍脉，不需要任何贴图。
- **LOD**：高模 15728 面、低模 4768 面；小鱼灯用低模。三角形列表在构建时按 part 切成
  **body / fin 两个索引缓冲**——两遍着色器各画自己的部分。
- 顶点着色器：摆尾波（从头部 0 到尾部 1 递增）+ 鳍片沿自身法线的高频抖动。
- **参数曲面的法线定向（11-20 修）**：`sheet()` 原来用 `refFn(0,0)` 这个**常量**判断朝向，
  鱼腹那一半的面全部被翻成朝上，侧腰因此有一条亮线折痕、眼珠出现多边形裂纹。
  改成每顶点调用 `refFn(u,v)` 后消失。给 `sheet()` 传 refFn 的一律要按 `(u,v)` 写。

**纸面（`FISH_FS`）**
- 拼贴纸：物体空间 3D fbm 做域扭曲 → 金/朱红/米白/青瓷/靛蓝的大色块（避开 UV 极点的同心环），
  再叠一层 `fwidth` 自适应淡出的鳞格与细纤维，远处不闪烁。
- 竹骨：横向 9 道环 + 纵向 10 根铁丝，随手做的轻微起伏，靠近鱼头处淡出。
- 鳃盖：一条随角度弯曲的折痕 + 亮边，让「头」从蛋形身体里分离出来。
- **灯心**：两个尺度 —— 宽而弱的「纸整体发光」(`1/(0.14+d²)`) 加上小而亮的
  「灯透过纸的芯」(`1/(0.045+4.2d²)`)，再乘视线掠射衰减、面板厚薄和纸色。
  这样中心是近白的暖芯，边缘保留朱红，不会整体糊成一张橘色贴纸。
- 金圈眼睛直接画在纸面上（到眼心的物体空间距离），黑漆眼珠是独立小球，只露一点点 —— 从任何角度都成立。

**鳍（`FISH_FIN_FS`，预乘 alpha 混合）**
- 膜：根部 0.86 不透明 → 边缘 0.3 → 到最外缘 `smoothstep` 溶解成空气。
- 鳍脉：沿 u 方向放射的细丝（20 条上下）、次生细脉、同心生长纹，全部 `fwidth` 抗锯齿。
- 灯透过膜：`pow(dot(-V, L)`) × 距离衰减，鳍正对灯时整片亮起；折叠处按法线与灯方向
  做明暗（`ndl`），所以丝绸会有起伏。
- 薄膜虹彩（视角相关的 `cos` 三通道相位）+ 玻璃边：最外 12% 环带加亮，逆光时更亮。
- 混合用 **`ONE, ONE_MINUS_SRC_ALPHA` 预乘**：既能发光，又能遮住背后的天空 —— 
  纯加性在亮天空前会洗成灰白，实测这是让它「像丝绸而不是塑料」的关键一行。

**美术第二轮（2026-11-20 凌晨，按参考图继续打磨）**

第一轮的鱼灯结构对了，但「像不像参考图」还差三点：纸面被灯心照得过曝、鳍偏灰白、胸鳍是叶片而不是水袖。这轮按「色 / 形 / 光」三件事重做：

- **纸面：从「渐变橙」改成「手撕拼贴」**
  - 之前用 3D fbm 直接混六种颜色，结果是均匀的橙黄渐变——灯一照就糊成一片。
  - 现在把噪声场**量化成连续纸片**：`levels = 5`，`pid = floor(n1*5)`，每片用 `hash21(pid)` 抽自己的纸色（朱红 / 金 / 米白 / 罕见青瓷、靛蓝、紫檀），片内再叠低频污渍；片与片之间画一条**手撕缝**（fbm 等值线 + 暗缝 + 亮纸茬）。等值线是连续团块，所以永远不会出现方格。
  - 去掉原来的鳞格晶格（`u*15 / v*24` 的鳞片格）与纵向铁丝网：特写下它们是「华夫饼格」，参考图里没有。现在只保留 7 道手扎竹骨环 + 细纸纤维（fbm2，各向同性）。
  - 灯心从「宽发光 + 白热芯」压到 `paperLit*0.13 + hot*0.048`，并把灯色从 (1.0,0.84,0.58) 调到 (1.0,0.78,0.50)：中心仍是暖芯，但纸的朱红/金/拼贴色不再被 ACES 洗成白色。
- **鳍：三段色带 + 金绑带 + 飘带胸鳍**
  - 颜色按 u 三段：根 (0.84,0.085,0.022) 朱红 → 中 (0.94,0.24,0.14) 珊瑚 → 梢 (0.94,0.46,0.37) 玫瑰白；外层再掺一层玫红洗染（`0.15+0.07*sin(finId*2.1)`）。删掉原来的白色 high-tip 混色——那一条是「灰白化」的元凶。
  - 鳍根 u<0.085 加**金线绑带**（`rootBand`），把膜和身体连起来，参考图里就是这个金箍。
  - 鳍脉从 18 条加到 27 条、加二次弯曲（`warp` 随 u² 增大），脉用亮色（`cTip*vein*0.10`）而不是暗线。
  - 胸鳍重写为**水袖飘带**：根部在鳃后下方，A 轴向后下方拖、B 轴沿身长，宽度根部 14% → 中部最宽 → 尖端收细，沿长度轴 `tw = 0.85u + ...` 自转卷曲、N 方向加 curl，边缘叠慢速起伏。长度 0.68 身长。
  - 尾鳍加长到 0.92、皱边加两档高频；背鳍加高并叠 5 个锯齿，做出参考图的「层叠帆」。
- **金饰：两道环 + 金瞳**
  - 新增 `goldBand(s0, halfWidth)`：沿身体截面采样一圈、径向外推 5.5 mm 的带状片，part 3 走「旧金漆」材质分支（压暗 + 锤纹噪声 + 高光）。一道在眼后（s=0.772），一道在尾柄（s=0.212）。
  - 眼睛：黑漆珠加大到 0.053 并细分到 16×28（特写不再是多边形）；纸面金瞳半径压到 0.062→0.056 的细环，外面再压一圈暗红眼窝；眼珠加一道月光 glint，任何角度都有高光。
  - 嘴唇环缩到 R=0.0165 并内推，不再像个红管道口。

**调色与迭代（studio 模式）**
- `?studio=1` 只画一条鱼、黑底、相机绕鱼轨道；`&angle=` 固定机位、`&draw=body|fin` 单独看纸面或鳍、
  `&look=x,y,z&dist=&fov=` 取头/眼特写。
- 定型后再回到场景：`?freeze=6&cam=x,y,z&look=x,y,z&fov=45` 冻结时间取确定性机位出图
  （`tools/final-stills.mjs` 里 09/10 就是这样拍的）。

### 3.4 程序化音频（`audio.js`）

全部 WebAudio 合成，无音频文件：粉噪声风（低通 + 0.055 Hz 阵风 LFO）、
D 小调持续 pad（8 个失谐锯齿 + 低通 LFO）、太鼓脉冲（正弦下滑 + 噪声皮）、
筝式拨弦（三角波 + 八度泛音 + 长衰减）、FM 钟声、程序化脉冲响应做卷积混响。
62 BPM 的 8 拍循环用 `setInterval` 前瞻调度。

### 3.5 交互（`camera.js` + `main.js`）

- **自由飞行**：WASD + QE 升降 + Shift 加速，指针锁定鼠标视角，速度带阻尼。
- **自动巡游**（空格）：Catmull-Rom 闭合路径穿过全城，镜头自动看向预设目标点。
- **8 个观景点**（1–8）：1.6 s 缓动过渡（位置线性插值 + 最短路径 yaw + fov 插值）；
  其中「鲤群」机位抬到鱼灯巡航的高度，正对 30 单位长的主鱼灯。
- **T** 切换「灯祭夜 / 薄暮蓝调」两套调色预设；**P** 摄影模式；**H** 帮助；**M** 静音。
- 支持 `?view=N`、`?tour=1`、`?noui=1`、`?hour=1`；截图专用参数
  `?freeze=T`（冻结时钟）、`?cam=x,y,z&look=x,y,z&fov=`（指定机位）、
  `?studio=1`（鱼灯单件 studio）、`?draw=body|fin`。

### 3.6 性能与诊断（11-20）

主循环这一轮按「先测后改」重做，完整报告见 `03-notes/perf-skycity-2026-11-20.md`：

- **诊断**：`?perf=1` 左下角覆盖层（GPU 型号、渲染倍率、画布/场景 RT、rAF fps、实测整帧 ms、
  显示 Hz 估计、软/硬件渲染、是否受垂直同步/串流限制）；同一份数据 `__sky.perf.snapshot`。
  正常 HUD 改成两行中文：`57 FPS · 1280×720 · 254k tris · 74 calls` / `GPU 0.3ms · 倍率 100% · 硬件加速`。
- **自适应分辨率重写**：用每 30 帧一次 `gl.finish` 的实测整帧耗时驱动（迟滞 + 冷却 + 120 帧 warmup），
  不再看 rAF 间隔；30Hz 垂直同步/串流不再误降档（`__sky.perf.testAdaptive(33.3,0.5) = 1.0`）。
- **鱼灯开销**：按屏幕投影高度分 high/low/tiny 三档 LOD + 两遍绘制共用的球-视锥剔除；
  绘制公共 uniform 只设一次，模型矩阵写进预分配 Float32Array；光点 top-5 无分配。
- **光晕**：每条鱼一张 shape 3 加性暖色 billboard（`FISH_HALO`），场景 pass 内、bloom 之前；
  bloom 亮部阈值 1.0→0.88。

| 1440×900 | 0.63 / 0.55 | 0.72 / 0.61 | 0.84 / 0.76 | 74 / 44 / 72 |

结论：**本机不是 GPU 瓶颈**；headed 的 56fps 是 60Hz 垂直同步封顶。若用户端只有 ~30fps，
先看 `?perf=1` 的判定行（软件渲染 / 串流限帧），不要盲降画质。

### 3.7 建筑精细化与街市（11-20 第二轮）

用户明确要求「建筑按参考图做精细（中国仿古木构）」。这一轮把町屋从「盒子 + 曲面屋顶 + 发光窗片」
换成**程序化仿古木构**，并把环街做成真正的夜市。施工规格先写成 `03-notes/building-spec.md`
（1 间 = 2.0 m 模数、构件尺寸表、色板 Y 值、三档面数预算、10 条静帧验收判据）。
实现分三块：**街市陈设 street.js / 建筑生成器 buildings.js / 街廓布局 town.js**。

**布局（`town.js`）**
- 环街在主岛下层台地：街心半径 45.5，内排立面 r=43（朝外），外排立面 r=47.9（朝内），街宽约 5 m。
- 内排 15 栋 + 外排 18 栋占满 a∈[0.12, 2.78] 的主景弧（正对 01/02/03/04/08 五个机位）；
  a∈[0.42, 2.08] 为 **hero 弧**（detail 2，约 3.7k 面/栋），其余 detail 1（约 1.1k）。
- 外排背后一排 **back row**（detail 1）补天际线；环街之外的其余弧段铺一圈 **稀疏远景排**
  （detail 0，约 250 面/栋），从任何方向看环街都不会「半路断掉」。
- 街两端各一栋 3 层转角楼收头；楼梯 / 鸟居（a=π/2±0.17）留空 14 m。
- **地形贴合**：新增 `src/terrain.js`，把 `islandTop()` 的岛面高度函数抽出来复用，
  建筑 / 灯柱 / 幡按岛面实际高度落地（以前固定 y=0.2，越靠岛缘越悬空 1–2 m）。
- **石板环街**：48 段石面带 + 两侧排水沟色带（288 面），跟着岛面起伏。

**建筑生成器（`src/buildings.js`，`buildMachiya(b, ctx, rng, opts)`）**
- 参数：面宽 4.8–7.2（2–4 间）、进深 4.0–5.8、层数 1–3（默认 20% / 66% / 14%）、
  层高 3.04–3.14 + 2.88–3.0、台基 0.48–0.56（埋深 0.7 吃掉地形起伏）、出檐 1.2–1.35、挑台 0.56。
- 构件：台基 + 3 级石阶、8 棱圆柱 + 柱础、长押 / 梁 / 挑梁、**深檐（瓦口 + 封檐板 + 椽头阵列 0.36 间距）**、
  腰檐（1F 庇 / 2F 庇 / 3F 庇）、**二层挑台 + 朱漆栏杆 + 台板挑梁**、格子窗（大格 / 虫笼竖棂 / 推开的障子）、
  暖帘、横匾 / 竖匾（自发光抽象字条）、幡旗、檐下灯笼（billboard，世界坐标）、山墙妻壁 + 博风板 + 悬鱼、脊瓦 + 鬼瓦。
- **半木构**：核心体是暖白灰泥 box，外披深色柱梁——靠「灰泥亮 / 木暗」的两档 Y 值拉开层次，
  避免整面墙糊成一块（规格 §4.1）。窗纸 emissive 0.26（hot 0.55），远低于第一版 0.98，不再整面过曝。
- **三档 LOD 是建模档**（世界是一张合并静态 mesh，没有运行时切换）：hero 3.7k / mid 1.1k / far 250 面。
- 屋顶：`roofGable()` 曲面檐口（举折 curve≈1.3、翘角 lift 0.5）、瓦垄亮条、椽头、博风板、脊瓦 + 鬼瓦。

**新增几何原语（`src/geo.js`）**
`bar3`（两点间方梁，12 面；椽 / 梁 / 撑 / 斗拱臂）、`fretGrid`（平面格子棂）、
`railing`（木栏杆：扶手 + 下枋 + 棂条 + 望柱）、`dougong`（3 段简化斗拱）、
`eaveRoof`（单坡腰檐：曲面 + 瓦垄 + 封檐 + 椽头 + 檐底）、
`roofGable`（切妻主檐：曲面檐口 / 瓦垄 / 檐底 / 椽头 / 妻壁 / 博风板 / 脊 + 鬼瓦）。

**街市陈设（`src/street.js`，`buildStreetFestival(b, ctx, rng, o)`）**
- 12 个屋台（柜台 + 柱 + 红白/靛白条纹雨棚 + 食盒陶罐 + 暖帘 + 布招牌 + 摊灯）、
  9 道跨街灯笼串（catenary + ribbon，4 m 高，两端木臂咬进立面）、7 杆幡、4 块竖招牌、5 处布雨棚、21 件零碎
  （长凳 / 木桶 / 货箱 / 石灯笼 / 火盆）。共 15.8k 面、82 盏灯笼 billboard、3 个点光；街心 1.9 m 净宽可通行。
- 预算与体检：`node tools/street-check.mjs`（面数 / 灯笼 / 点光 / 占道 / 确定性 / 变换栈泄漏 全绿）。

**这一轮挖出来的三个真 bug**
1. **torii() 的变换栈泄漏（最重要的一个）**：`torii()` push 3 次（translate / rotY / scale）只 pop 2 次，
   于是从第一个鸟居之后的**所有几何**都被乘法叠加的变换带走——整座小镇被平移到 y+19 / z+59、
   并绕 y 轴翻转缩放。表现是「街拍画面里没有房子，远处却有一排小房子」。
   修法：补齐第 3 个 pop；并用 `node _leak.mjs`（临时脚本）把 `B.push/pop` 包一层、
   在构建结束后打印仍然挂在栈上的 push 调用栈，一次定位所有不平衡点（修完 LEAKED = 0，town bounds 回到 ±55）。
2. **挑台层窗被核心体挡住**：2F 立面为做挑台深度内退 0.34，但核心体只内缩 0.14，
   于是 2F 窗纸（再内凹 0.06）全部藏进核心体里——远处看 2F 是一面暗墙。修法：有挑台时核心体内缩到 d-1.0。
3. **零法线导致黑色大块**：退化三角形的自动法线是零向量，`normalize(0)` 未定义，
   整个光照和变成 NaN → 屏幕空间出现纯黑大方块。修法：`geo.js tri()` 对零长法线回落 [0,1,0]，
   并在 `LIT_FS` 里加一道 `dot(N0,N0) > 0.25` 的安全阀。

**建筑 look-dev（`?lab=1`）**
- 新的调试模式：只画**一栋町屋**、暗场、相机绕行。参数 `?lab=1&angle=&dist=&eye=&fov=&floors=&detail=&w=&d=&seed=`。
  和鱼灯的 `?studio=1` 对称，是这一轮迭代建筑的主要工作方式（实验室截图见 `04-output/skycity/_look/`，不入成品）。
- 另有临时诊断开关 `?no=static|world|fall|bb|cloud|puff|halo|bloom`，用来隔离某个 pass 排查渲染问题。

## 5. 已知取舍

- 无阴影贴图：夜景里月光很弱，靠「顶点色烘焙 AO + 边缘光 + 自发光 + 点光」撑体积感；
  加 CSM 会让 30 万面的场景多一遍几何 pass，收益不高。
- 云海是单层位移高度场 + 伪法线，不是体积云；岛屿遮挡云海没有真实投影，用「城市暖光晕染 + 雾」掩盖。
- 灯串/天灯是公告板，凑近看是纸片；在飞行速度下不明显。
- 场景是「可游览的展示」，没有碰撞和玩法；鱼灯不参与交互。
- 鱼灯的鳍是单层薄面：加法/预乘混合不排序，所以「近鳍压远鳍」「鱼身挡住背后鳍」这类顺序
  只是深度测试的近似，特写时凑近看能看到；飞行视角下无感。
- 鱼灯仍是场景几何的大头（高模 17.1k 面/条）；小鱼已减到 20 条并加 tiny LOD，再减会影响灯祭密度。
  如果仍嫌重，优先给 FISH_FS/FISH_FIN_FS 加 uLod 分支跳过高频噪声（本机 GPU 不是瓶颈，收益主要在软渲染机器）。
