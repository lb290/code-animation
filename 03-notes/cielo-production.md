## 2. 渲染管线（每帧）

1. **太阳阴影**：2048² depth-only 正交投影（覆盖 ±560 m，中心 (0,6,-50)），
   静态世界 + 动态 model actor 进 depth pass；lit.fs 里 3×3 PCF + 法线偏移防 acne。
2. **天空**：全屏方向着色 —— 天顶钴蓝→中天青→地平乳白渐变、太阳光晕、淡月亮、
   高层卷云、两层积云（密度 fbm + 密度梯度假法线 → 顶亮底暗）。另有 billboard
   积云簇（底宽顶圆的三排 puff）补出"厚涂积云"。
3. **静态世界**：所有建筑/桥梁/栏杆合并成一张 mesh，一次 draw call。
4. **动态 actor**：ctx.dyn 里的 model（矩阵每帧算）与 inst（实例化，fill 回调）。
5. **Billboard**：静态云海/气球 + 动态花瓣/蒸汽/光尘（形状 0–6）。
6. **加法特效**：鲸鱼辉光等（blend ONE）。
7. **后处理**：亮部阈值 → 两级高斯 → composite（ACES-ish tone map、饱和度 1.22、
   暗部蓝紫 lift、vignette、颗粒、**FXAA**）。自适应分辨率（帧时 >27 ms 降档 / <15 ms 升档）。

## 3. 美术关键决定

- **卡通三段光**：lit.fs 用 smoothstep 压出 band/cap 两段明暗，阴影保留蓝紫（uShadowTint），
  阴影里仍留 0.30 的主光，避免画面脏。
- **反照率 0.45–0.85**：早期近白石材叠加主光+环境光后整屏过曝，改成米黄（#ddd2b8 等）
  才留得住颜色。
- **空气透视**：fogDensity 0.00125 + 1.18 次幂 + 高度衰减，远景褪成 #c8e4f6。
- **浮空岛**：城市坐在半径 560 m 的浮岛圆台上，外圈石栏 + 分层崖壁，崖下 y≈-240 云海
  由 680 个 billboard 云团铺成；远空另有 9 座崎岖浮岛（径向噪声）与塔楼。
- **确定性**：所有随机走 mulberry32(seed)，静帧可复现。

## 3.6 收尾时修的最后一个视觉 bug

画面里曾有一条贯穿全屏的橄榄绿亮带：**每栋楼的孟莎顶金色脊线 + 檐口金线同高成排连成一片**，
在 bloom 与曝光叠加后过曝成跨屏亮带（不是 NaN、不是超大面片）。修法：脊线改哑光石材、
只在四角留金饰；同时给 6–8 层立面每层加双阶连续檐口亮线，远看立面更有节奏。

## 4. 已知坑

1. B.push() 必须是 **16 个 float**；漏掉末尾的 1 会让之后所有几何变 NaN（geo.js 会 warn 修复）。
2. 每个 push 必须配对 pop，否则之后的几何被叠加变换带走。
3. 不要把 shot.mjs 放进管道（竖线 tail / head）—— 会静默不截图。
4. 顶点/索引必须来自同一个 B（否则 WebGL 报 "Vertex buffer is not big enough"）。
5. 实例化 actor 的 capacity 必须 ≥ fill 返回的实例数（InstActor 会 clamp 并 warn）。

## 5. 第二轮：巨鲸重做（2026-11-21 下午）

用户对第一版巨鲸的四条意见：**城堡太靠后 / 城堡下面有一块大圆盘土地 / 鲸鱼要放大好几倍、
背上应该是另一个城市 / 鲸鱼要更像、更精细**。这一轮只动 `whale.js`（重写）、新增
`whale-city.js`、新增 `glsl/whale.fs.glsl`，并小幅改 `layout.js` / `camera.js` / `main.js`。

### 5.1 尺寸与巡游

- 局部坐标仍是 260 m（`NOSE=130 / TAIL=-130`），**渲染时 `trs(..., scale=3)` → 世界 780 m 长、
  约 150 m 高、180 m 宽**。腹部最低点离地 ~300 m，鲸背城市顶 ~470 m。
- `L.whale = {cx:10, cy:420, cz:-110, radius:340, speed:0.0115}`：一圈约 9 分钟，
  t≈8 s 时鲸心在 (-259, 428, -317)（观景点 2 / 7 就按这个时刻构图）。
- `camera.js` 的飞行上限从 `y≤460` 抬到 `y≤1150`、xz 到 ±1500；巡游样条加高到 y≈450 飞到鲸背高度。

### 5.2 形体（做「像鲸鱼」的关键）

- **KEYS 剖面表**：u=0→1 共 20 个截面，每项含 半宽 / 上高 / 下深 / 中心 y / 白腹边界 / 顶面平坦指数。
  头大而钝（u≤0.19 宽 24 m 级）、喉部深（u=0.36 下深 32.6）、尾柄明显收细（u=0.885 只剩 5.2 宽）。
- **顶面平坦指数**（`surf()` 里的 `1 - |cos|^P`）：城市段 P=4.4~4.8，压出一片**宽阔平背**给城市站；
  头部 P=3.2~3.9 做出钝而宽的额头；尾部降回 2.2 恢复圆尾柄。
- **喉褶**：真实几何位移（`cos(tc·π·9)`，振幅 0.034 半径，u∈[0,0.34]），配合烘进顶点色的
  明暗（`0.87 + groove*0.22`），仰视时能读出纵向褶。
- **配色**：深靛蓝背 → 钴蓝侧 → 水线青 → 近白腹；边界用两层 noise 扰动 + ±0.06 的软过渡
  （不再是「画上去的直线」）；脊柱亮带、斑驳、藤壶白点、旧疤条纹。
- **鳍**：`airfoilFin()` 通用翼型发生器（每截面 中心/展向/弦向/厚度 + 上下表面 + 前缘后缘条）。
  胸鳍是 14 段贝塞尔弯叶（世界长 ~130 m），尾鳍两叶带中心缺口、后掠、下垂，背鳍钩状后置。
- **细节**：双喷气孔（椭圆凹 + 周围隆起）、眼睛（暗斑 + 眼珠 + 高光）、藤壶群（18 处）、
  唇线（暗缝 + 下唇浅色条）。删掉了会在额头上读成接缝的「鼻梁管」。

### 5.3 巨鲸着色器（`glsl/whale.fs.glsl`）

从 `lit.fs.glsl` 派生，三处改动：
1. **wrap 主光**：`wrap=(ndl+0.62)/1.62`，腹部也有柔和主光，不再只靠环境光塌成一块；
2. **云层反弹**：环境光 ×1.9，并在 `-N.y` 方向补 `uSkyColor*0.085`，从下往上看腹部是发光的浅蓝；
3. **不自阴影**：`sunShadow()` 直接 `return 1.0` —— 780 m 的躯体在 2048² shadow 覆盖外会自遮蔽出
   一道硬边横贯腹部。
`main.js` 里新增 `P.whale` 程序，`ctx.dyn` 里 `prog:'whale'` 的 actor 走这条管线（阴影 pass 仍会画它们）。

### 5.4 鲸背城市（`whale-city.js`，子代理 citysmith 写 + 主代理集成）

- 约定：**真实米制、y=0 平地、+Z 朝鲸头、|x|≤63、z∈[-120,120]、最高 74 m**；`buildBackCity(b,rng,opts)`
  不认识鲸鱼。主代理用 `translate(0, CITY_Y, CITY_Z)` + `scale(CITY_CS/S)` 放进鲸鱼局部空间。
- 内容：哥特双塔大教堂（正立面 z=65、后殿 z=8、玫瑰窗、飞扶壁、73 m 尖塔 + 金十字）、
  25 栋街区、19 座附属小屋、八边形城墙 + 9 塔 + 正门、喷泉广场、花园树、暖窗；
  约 **3.9 万三角形 / 660 行**，自检工具 `tools/backcity-check.mjs`（面数/占地/穿模/栈深度/确定性）。
- 用户嫌的「大圆盘土地」在 `whale.js backShelf()` 里解决：岩台轮廓只比城市大 1 m 左右，
  台缘是石砌挡土墙（三段岩层色）+ 岩石露头 + 藤蔓，外面再套一圈**鲸皮起隆**（蓝皮肤鼓包），
  从侧面看城市像从鲸背上长出来。

### 5.5 众多鲸鱼城市

`POD` 里 4 头：各自独立的轨道圆、高度 540–860 m、轨道直径 600–900 m、scale 2.0–2.8；
低模躯体（su=26/ns=16）+ 暗色塔楼剪影群（约 3 千面/头），共用一张 mesh、4 个 model 矩阵。

### 5.7 修掉的旧 bug

- `arch.js mansard()` 第 316 行把三角山花写成了 `b.quad(...)`，`MT.stone`（[0,0.1]）被当成颜色，
  产生一批 NaN 颜色顶点 —— 这是第一版画面里「荧光黄绿色竖条/横线」的根因。改成 `b.tri(...)`。
- `city.js` 第 923 行 `mulc(C.lawn, C.leafLight, 0.2)`（应 `mixc`）产生 NaN 颜色的小广场草盘。
- `geo.js B.vert()` 增加颜色兜底 + 调用栈警告（`[geo] bad colour`），以后同类错误一眼定位。
- `whale-city.js` 自检里也加了「非有限颜色 = 0」检查。

### 11.1 红框 → 世界坐标的反推方法

用户只给了一张俯视截图（1269×874）+ 红框，没有相机参数。做法：
1. 在截图里认出 5 个已知世界坐标的地标（喷泉 (0,−46)、车站 (58,−146)、大教堂 (−96,−24)、

### 13.2 三条工程结论（以后加室内建筑直接照用）

1. **选址先做占位图**：把 `ctx.footprints`（476 栋）+ 铁路曲线 + 地标保留区画成 2 m 网格占位图，
   才发现城市内环几乎全是保留地/广场，而「运河 + 大道尽头」是唯一同时满足「零街区重掷 / 铁路 66 m / 视野带外」
   的空地。新增 `RES_RECTS [0,-232,42,40,4]` 后城市三角**逐字节不变**（2,048,729 基线保持）。
2. **实体楼梯塔与空腔的冲突用「豁免圆柱」解决**，不要为了体检把塔做小/挪走：`TURRET_EXCLUDE`
   （中心 (0,−16.5)、r 3.95、y −5.2..88.6）写进契约，checker 同时打印「原始 / 排除后」两套计数，
   排除后必须 0；原始计数（918/747/747/496）就是塔本体，属设计而非 bug。
3. **契约里的 helper 也要被体检**：`annulusXZ(r0=0)` 原来写成 `tri(centre,p1,p2)`，r0=0 时 p1=圆心 →
   零面积三角形 + 圆心顶点掉进空腔（被 cloudwell-check 的 cavity 断言抓到 48 个）。改成 `tri(centre,p2,p3)`。
