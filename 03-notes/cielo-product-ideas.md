# CIELO 产品改进方案 · PRODUCT IDEAS

> 规则：每轮**列出两个**候选方案，**推进一个**（做到能验收、能演示），另一个留在本文件等下一轮。
> 判断标准：① 对"来逛一座城"的人有真实价值；② 复用现有系统，不另起一套；③ 验收可判定（能写进 checkall / mobile-check）；④ 桌面体验零回归。

## 已完成

### 方案 A · 明信片工坊（Postcard Atelier）—— Round 11 推进 ✅

**问题**：这座城很好逛，但逛完什么也带不走。用户会截图，截图里有 HUD、有卡片，不像纪念品；在平板上也没有"分享给朋友"的顺手动作。

**方案**：任何机位按 **C**（触屏「明信片」按钮）→ 暂停这一刻，生成一张 1440×960 的明信片：
- 纸边 + 金色内框 + 院徽菱形 + 编号（POSTCARD No. 月日）；
- 画面用 `gl.readPixels` 取 WebGL 帧缓冲，**不带任何 UI**；低画质档下临时抬到 1.0 倍渲染一帧再截（只多一帧，不改用户的画质设置）；
- 地名按城区锚点判断（露台 / 大道长街 / 中央广场 / 王宫 / 玻璃宫 / 大教堂 / 高架车站 / 歌剧院 / 巨鲸与鲸背城 / 云上茶席 / 云海），阈值之外写「云端漫游」，不张冠李戴；
- 落款：昼夜（白昼 / 黄昏 / 夜晚）+ 日期；
- 「保存图片」下载 PNG；「分享」走 Web Share API level 2（安卓 Chrome 支持直接分享文件），不支持时提示用保存。

**验收**：`tools/mobile-check.mjs` 断言打开明信片后 `#pc-img` 的 dataURL > 50 KB；桌面按 C 也能出片。

**后续可加**：3 套纸样/边框、加一句自选题词、明信片背面（竖排地址栏）、把「保存」接到系统相册（File System Access API）。

## 待推进

### 方案 B · 主题航线 · 导览巴士（Guided Routes）—— Round 12 候选 📋

**问题**：31 页抄本 + 80 个观景点，第一次来的人不知道"该按什么顺序看"。现在只有一条 108 秒的自动巡游（`cam.startTour()`，走的是固定镜头曲线），它好看但不讲解，也不停站。

**方案**：在抄本首页加三条主题航线，每条是一个有序站点表（观景点 + 对应 LORE 页 + 停留秒数）。点「启程」后：
- 相机用现有的 `cam.setView(i)` 平滑过渡（1.7 s）到下一站，停留 12–15 s 让用户看/读；
- 每到一站自动在抄本里翻到对应页（复用人话抄本的 `openAt`），卡片照常弹；
- 底部/抄本内显示「第 3 / 7 站 · 下一站：玻璃宫星象台」，可「暂停 / 继续 / 退出」；
- 任何手动操作（推摇杆、拖视角、按空格）立即退出航线并 toast；桌面与触屏同一套按钮。

**三条候选航线**：
1. **建筑朝圣**（7 站）：大教堂全景 → 大教堂中殿 → 车站车棚 → 歌剧院观众厅 → 王宫圆厅 → 玻璃宫蓝色大厅 → 玻璃宫星象台；
2. **童话奇观**（7 站）：露台初见 → 少女与花 → 空中鱼群 → 云上茶席 → 温室雨林 → 玻璃宫镜池 → 夜空白昼切换；
3. **云端秘境**（5 站）：鲸临城上 → 云上鲸背 → 云海边缘 → 银轨绕宫 → 云上茶席。

**实现要点**：航线数据放 `src/routes.js`（id / 名称 / 站点[view, loreId, 停留 s]）；状态机放 `main.js`（`route = {id, i, t, paused}`），每帧推进；UI 在抄本头部加「航线」页签（触屏用按钮）；`?route=architecture&freeze=` 可截图验收。
**验收**：新增 `routes-check.mjs`（站点 view 索引合法、至少覆盖 5 条 LORE、每条 ≤8 站）；`mobile-check` 增加"点启程后 30 秒内相机到过第 2 站"；桌面巡游/观景快捷键行为不变。
**风险**：站间镜头过渡会穿过建筑（只过渡位置，不做路径避障）——属可接受的"导览车"感；退出航线要恢复用户原来的机位。

## 备选池（还没排期）

- **语音导览**：用 Web Speech API 念抄本正文（安卓 Chrome 有中文语音；无声时静默降级）。适合平板，但语音质量取决于系统 TTS。
- **游客护照**：抵达一处盖一个章，集齐 31 页生成一张"通关证书"（复用明信片出片管线）。
- **时间流转**：白昼→黄昏→夜晚自动缓慢循环（10 分钟一圈），配上"此刻该看什么"的提示。
- **天气/云层变化**：云海高度随"时辰"变化，影响俯瞰效果。
- **分享链接**：把当前机位编码进 URL（`?cam=` 已有），做「把这一刻发给朋友」的短链。
