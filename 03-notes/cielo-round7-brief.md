## 2. 总原则（两位施工员都必须遵守）

- 工程：自研 WebGL2 单文件场景（无 three.js）。几何用 `src/geo.js` 的 `B` + `src/lib3d.js` 图元。
  顶点 pos(3) normal(3) color(3) mat(2)=11 floats；材质 `mat=[emissive, gloss]`；反照率 0.45..0.85 线性 rgb。
  坐标直接用**世界坐标**（rot=0，local = world），不要再用 `frameMap`。
- **随机数**：只用模块内 `const R = mulberry32(固定seed)`（`import { mulberry32 } from './math.js'`），
  **绝不要用 world.js 传进来的 `rng`**（那会平移其它模块的随机序列）。
- `b.push()` 必须 16 float、push/pop 配对；模块抛错会被 world.js 的 try/catch 兜住（只 warn 不黑屏），但你要保证不抛。
- 室内没有真实光照通道：室内石/金/木要带 emissive lift（0.10..0.26）+ `ctx.points` 暖色点光
  （每个室内 ≤8 个，range 18..46，int 0.35..1.0）+ `ctx.lanterns` 暖光 billboard（shape:1，size 0.6..3，alpha 0.3..0.8）。
  点光全局只有最近 12 个名额，别堆在同一个机位。
- 观感基线：日系动画白昼 + 宝石蓝玻璃 + 金色描边；夜间照明由既有昼夜系统自动处理。
- 三角预算：全局上限 2.2M（本轮开工前静态 ≈1.5M）。每个新模块 120k..240k。单文件最终 < 2.2 MB。
- **不要修改别人的文件**：只写你自己名下的 `src/<你的楼>.js` 和 `tools/<你的楼>-check.mjs`。
  不要碰 `world.js / layout.js / landmark.js / city.js / rail.js / palette.js / main.js / HANDOFF.md / README.md / 03-notes/`。
- **不要跑 `node build.mjs`（不带 --as）**：统一 `node build.mjs --as=<你的名字>` → `04-output/CIELO.<名字>.html`。
  服务器已在 http://127.0.0.1:8099 跑着（静态目录 04-output；没跑就 `node tools/serve.mjs`）。
